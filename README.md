One editorial poster for Monday 23 November 2026. Six short panels cover the
day's main stories: the COP31 climate summit closing without a deal, the
drone strike on a Russian ship off Libya, the Indonesian factory fire, the US
House result, the rise in ship attacks near Hormuz, and the EU–Indonesia trade
agreement. The date is printed in the header, on every panel and in the footer.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program only copies `entry.png` into the output directory, so two runs
write identical bytes and no network access is needed.
